# Simplified R2 setup verification

## Scope and implementation

The user accepted simplifying the R2 form and requested `work-until-grill`, with
`rule-lean` guiding implementation. This run covers [FEAT-media](../../features/media.md)
setup, its shared upload validation, and the existing upload regression suite.
The implementing agent performed the checks; no independent review is claimed.

The normal form has five connection fields and collapsed Advanced options.
Standard S3 endpoint pastes extract the account ID and optional bucket; account-only
endpoints preserve the bucket. Public URL and credential hints explain the Cloudflare
steps. Copy CORS policy uses the current editor origin, with a manual-copy fallback.
The form owns uncommitted edits. Save validates, then stores/applies them; Cancel,
Escape and dismissal discard edits. Success describes saved settings without claiming
a verified connection. No backend, dependency, live connection probe or token creation
was added.

## Build and environment

macOS, Node 22.19.0, pnpm 10.34.1, Chrome. Base revision
`5a14f1a526e6c82efa0eb1c15a03ea3bf0a76801`, with existing uncommitted Intr example,
catalog optimization and documentation changes preserved. The
[source manifest](../../evidence/2026-10-13-r2-setup/source-manifest.json) fingerprints
the dirty build inputs and confirms the four changed application files matched the
browser fixture.

An isolated Intr checkout was prepared with `node scripts/example-site.mjs intr prepare`,
built using `pnpm build`, and served with `python3 -m http.server 4325 --bind 127.0.0.1
--directory dist` from that copy. Its fixture login and dummy R2 credentials were used.
Root content, existing user browser drafts and servers were untouched. Desktop:
1440 × 1000; narrow viewport: 390 × 844. [Fixture build log](../../evidence/2026-10-13-r2-setup/fixture-build.log).

## Limits and cleanup

Live R2 credentials, permissions, CORS, public reads, browser image encoding and
object cleanup were outside this setup-only run and remain unverified. Saving settings
does not establish them. Jurisdiction-specific S3 endpoints remain unsupported.
Responsive viewport checks do not establish physical-device or cross-browser behavior.
The session-storage failure path was covered by a throwing component callback and
handler inspection, not a browser storage-quota failure.

The temporary viewport override was cleared, the owned tab closed, and the owned
HTTP server stopped. The isolated checkout remains in the OS temporary directory;
evidence remains in this repository. No commit, push, deployment or Cloudflare account
change was performed.

The wiki reader was rebuilt and its integrity check passed. The report metadata
checker accepts this run but still flags four pre-existing legacy result labels
(GitLab, local authoring, Quine and Intr), preserved from before this task. See
[checker output](../../evidence/2026-10-13-r2-setup/report-metadata.json).
