## Limits and cleanup

Browser verification used development output; production was checked through the real build and emitted HTML, not a second browser server. GitHub/R2/hosting operations are outside this change and were not exercised. Font availability depends on the visitor's system with defined fallbacks; this version offers built-in stacks, not uploaded/web fonts. Blocks may override shared defaults by design. Screenshots were visually inspected, not stored as image evidence. The owned test window was closed; the user's existing window and development process remain running. No provider state or fixture content was changed by browser checks.
