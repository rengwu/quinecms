# Declared collection rendering and Tessera verification

## Scope and source

DEC-188 implements the [accepted field contract](../../discussions/tessera-collection-context.md).
The same work recreates all 59 reachable navigation-linked Tessera pages as a
library design, 16 block versions and an explicit starter, independently copied
into the dev site after backing up Archline.

This is verification of working trees, not a released commit. Engine 0.3.0 and
library 0.2.0 remain local source versions; the dev site links both siblings.
[Source SHA-256 inventory](../../evidence/2026-10-16-tessera/source-sha256.json)
records tracked/untracked source files, excluding engine docs and dev backups.
It identifies the prior commits where available; dev-site has no initial commit.
Existing unrelated engine changes were preserved. The Archline pilot working tree
is clean and its dependency pins were not changed.

## Delivery and limits

The dev site remains running at port 4322. Library defaults, starter configuration,
assets and implementations live in `quinecms-library`; the site's independent
content is in `quinecms-dev-site/content`. Archline's verified 44-file archive and
SHA-256 manifest remain under the dev site's
`backups/archline-20261016-050638/` directory.

Detailed Framer animation, external product services and persistent feedback are
intentionally omitted; simple local interactions and editable content preserve
the useful core. These checks do not claim pixel-identical output, every visual
state on every browser, or a universal no-regression guarantee. Existing
Archline/Intr automated coverage passed; those designs were not fully visually
retested in this increment. Git/R2 integrations, live hosting and a remote pinned
upgrade were not exercised. No deployment or publication was performed.
