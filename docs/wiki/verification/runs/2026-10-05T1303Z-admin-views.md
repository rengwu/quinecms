## Limits and cleanup

An initial attempt to load the entry's rich-text widget blanked the development UI. Safari's console identified HTTP 504 `Outdated Optimize Dep` for Lexical modules. A browser reload alone reproduced it. Touching the unchanged Astro configuration refreshed the existing development module graph; reloading and repeating the journey then loaded the rich-text toolbar and body successfully. This was a development-cache recovery; no widget or provider code changed.

Browser checks used desktop development output and made no content edits. Production was built and artifact-checked without a separate production-browser run. Live providers, media uploads, a full responsive/accessibility audit and rich-text formatting changes were outside scope.

The owned test window and its inspector were closed; Save draft was disabled before closing. The original user window and existing server were preserved. No new server, provider operations or content-file mutations were introduced by verification.
