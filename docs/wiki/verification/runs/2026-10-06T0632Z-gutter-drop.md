# Gutter drop regression verification

## Scope

[FEAT-editor](../../features/editor.md) and [FEAT-block-library](../../features/block-library.md). The shared sortable list cleared its target when hit testing found the list's gap instead of an item. It also used the previous pointer-move target on release. The repair resolves gaps to adjacent insertion positions and hit-tests the actual release coordinates, retaining cancellation outside the originating list. This applies to page blocks and repeated content without changing spacing or the field model.

## Limits and follow-up

The automated regression demonstrates the event-handler fix with explicit geometry; it does not prove native pointer capture or visual feedback across browsers. When browser access is available, drag repeated items up/down and release at several points within a gutter; verify the indicator and final order, then cancel by releasing outside the list. The aggregate remains Untested because that selected native check is outstanding. No provider data, content files, browser sessions or server processes were changed. Logs are retained, scratch logs removed; verification was by the implementing agent.
