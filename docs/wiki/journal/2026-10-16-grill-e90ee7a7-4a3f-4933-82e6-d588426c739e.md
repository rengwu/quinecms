## Question 1

```text
Round: Entry preview — remaining decisions
Question: What should the entry editor show when its collection has no generic page?
Description (Markdown source):
These are data-only records, such as authors or categories. They have no page of their own, although other pages may display their values. Entries with an assigned generic page will use the agreed fields-left, live-preview-right view.
Recommendation: Keep the existing full-width field editor for data-only entries. This reuses current behavior and avoids introducing a page picker or guessing where the record should appear.
Options: Keep the full-width field editor / Let the editor choose a page that uses this entry
Selected: Keep the full-width field editor
```

## Question 2

```text
Round: Entry preview — remaining decisions
Question: Should the entry editor provide a shortcut to edit its shared generic page?
Description (Markdown source):
The entry inherits its template and site layout from the collection. Editing that generic page affects every entry using it. The shared template is already accessible through Pages; the proposed shortcut is optional.
Recommendation: Show the template name as read-only information for this increment. It explains the preview without adding navigation or a return-to-entry flow.
Options: Show the template name only / Show the name with an Edit shared template link / Add no template information
Selected: Show the name with an Edit shared template link

```

## Question 3

```text
Round: Entry preview — remaining decisions
Question: When editing an existing entry, should links inside its preview navigate the editor?
Description (Markdown source):
The current page preview can open another page or entry when a layout navigation link resolves to a known document. Ordinary block-link behavior depends on the existing renderer. The choice here is whether to reuse that navigation behavior or make entry previews stay on the current entry. Pending new entries will keep their creation form in place until Create or Cancel.
Recommendation: Reuse the existing page-preview navigation behavior for existing entries. Unsaved entry edits remain in the shared draft, and we avoid introducing a separate interaction mode.
Options: Reuse existing page-preview navigation / Keep the preview on the current entry
Selected: Reuse existing page-preview navigation
```
