Round: Upload from media fields
Question: Should we add a thumbnail to the field too?

Round: Upload from media fields
Question: What should happen if storage has not been set up?
Description (Markdown source):
Browser uploads currently need R2 settings. We can open the existing storage dialog without leaving the block, or show instructions to configure it from Media. After saving settings, the user clicks Upload again.
Recommendation: Open the existing storage dialog from the field. It reuses the current setup form and keeps the user in place.

## Question 3

```text
Round: Upload from media fields
Question: If you cancel block changes after uploading, should the file stay in Media?
Description (Markdown source):
Cancelling restores the block's previous selection. The new file has already been uploaded to R2. Keeping it in Media makes it available for another block. Discarding it would need extra cleanup that checks it is not used elsewhere.
Recommendation: Keep the uploaded file in Media. Cancel undoes the block edit, and the file remains reusable.
Options: Keep the file in Media / Discard the new file if it is unused
Selected: Keep the file in Media
Notes:
```
