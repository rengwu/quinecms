## Question 1

```text
Round: Multiple site layouts — round 1
Question: How should a new page get its layout?
Description (Markdown source):
Every page needs one active layout. Changing this choice later keeps the page's blocks.
Recommendation: Select it automatically when only one layout is active. When several are active, require a choice before creating the page. This avoids a separate default setting or hidden inheritance.
Options: Only one: select it; several: ask me to choose / Keep a default layout, preselected for new pages
Selected: Only one: select it; several: ask me to choose

```

```text
Round: Multiple site layouts — round 1
Question: Should collection entries all use their generic page's layout?
Description (Markdown source):
For example, every Journal article uses the layout selected on the Journal generic page. That generic page counts as using the layout even when it has no entries.
Recommendation: Yes. Keep the layout choice on the generic page, with no separate layout choice on each entry.
Options: Use the generic page's layout for every entry / Allow individual entries to choose a different layout
```

## Question 3

```text
Round: Multiple site layouts — round 1
Question: Should a newly created layout start on or off?
Description (Markdown source):
Create adds a named layout with its own settings. An off layout keeps its settings but cannot be selected by pages.
Recommendation: Start on after Create, so the new layout is immediately available. Existing pages keep their current assignments.
Options: Start on / Start off until I turn it on
Selected: Start on
Notes:
```

## Question 4

```text
Round: Multiple site layouts — round 1
Question: Can an existing saved layout change to a different design?
Description (Markdown source):
For example, change Main website from Starter to Archline. Their settings differ, so a design change would start with the new design's defaults and affect every page using that saved layout.
Recommendation: Keep its design fixed. Create another layout and reassign pages when changing designs; this avoids silently resetting shared settings. Editing settings and choosing retained versions of the same design remain separate.
Options: Keep the design fixed; create another layout to change it / Allow changing design, with a warning before resetting settings
Selected: Allow changing design, with a warning before resetting settings
Notes:
```
