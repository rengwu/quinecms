## Question 76

```text
Round: Site Layout — code updates
Question: Should layouts retain selectable code versions, like blocks?
Description (Markdown source):
As the library grows, you may release a changed implementation of an existing layout, including changes to its appearance or settings. With retained versions, a site can keep chartr v1 after chartr v2 is installed, and upgrade deliberately. With one implementation per layout ID, deploying updated source updates that layout for the site. This concerns layout code, not remembering settings for inactive layouts: the site still stores only the selected layout and its current settings.
Recommendation: Retain versions and pin the selected implementation, matching blocks. This keeps existing client sites on their chosen layout implementation until an explicit upgrade, at the cost of maintaining older code.
Options: Retain versions; upgrade explicitly / One implementation per layout; update through code
Selected: Retain versions; upgrade explicitly
```
