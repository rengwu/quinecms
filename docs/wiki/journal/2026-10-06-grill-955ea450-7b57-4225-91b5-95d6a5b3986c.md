## Question 74

```text
Round: Site Layout — library and whitelist
Question: Which layouts should be available when the whitelist environment variable is not set?
Description (Markdown source):
The repository will accumulate layouts as you develop client sites. A configured whitelist will expose only the selected layouts. This choice defines the default for a development checkout or deployment with no whitelist configuration.
Recommendation: Show the full installed library when the variable is absent. Configure a whitelist when a client should see a smaller selection.
Options: Show all installed layouts / Require an explicit whitelist before the site can run
```

## Question 75

```text
Round: Site Layout — library and whitelist
Question: What should happen if the whitelist excludes the site's currently selected layout?
Description (Markdown source):
For example, the site currently uses Editorial, but the deployment whitelist is changed to Studio and Portfolio. One approach requires the developer to reconcile the active layout and configuration. Another keeps Editorial rendering with its current settings, but hides it from the picker; after switching away, the editor cannot select it again.
Recommendation: Reject the configuration/build until the active layout is allowed or an allowed layout is selected. This keeps the whitelist consistent without silently changing the site's design or resetting settings.
Options: Require the active layout to be whitelisted / Keep the active layout working; restrict future choices
Selected: Keep the active layout working; restrict future choices
Notes: 
```
